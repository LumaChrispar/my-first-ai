What this is, and what it cannot do

Aster is a tiny experimental neural network (~124K parameters) written from scratch in C and running entirely on this computer. It has no reliable knowledge — it does not know who you are, what year it is, or how anything in the world works, and it cannot look anything up.

It has no web access, no tools, and no persistent memory. Its replies are frequently wrong, incomplete, or incoherent. Treat every reply as unverified machine output, never as a fact or advice.

Where this runs and where your words go

The server is a single process on this machine, bound to 127.0.0.1 only. Nothing is written to a server-side log. This page loads nothing from the internet.

Your transcript is kept only in this browser's localStorage and sent only to the local Aster server when you chat. Clear erases it. The server does not save it.

The model is not trained — no replies can be generated

No checkpoint is loaded on the server, so it has nothing to generate from.
